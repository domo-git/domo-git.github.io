Threat Actor Profiling – Ransomware TTP Analysis

Project Overview

Structured profiling of known ransomware groups, focusing on TTP patterns, infrastructure behavior, and operational methodology. Analysts can leverage current threat intelligence feeds to stay informed about emerging campaigns.

Hands-On Replication

To gain practical experience, you can replicate key phases of ransomware behavior within a secure virtual lab:

  • Set up a small AD environment (1 Domain Controller, 2 Workstations, 1 File Server).
  • Simulate initial access attempts using safe brute-force tools or test accounts.
  • Deploy benign credential extraction scripts to understand telemetry (never use actual malware).
  • Track lateral movement by creating mock services and monitoring Event Logs.
  • Test file encryption with temporary directories and shadow copy removal in a controlled environment.

Following these steps gives insight into how ransomware behaves in enterprise networks while keeping the environment completely safe.
