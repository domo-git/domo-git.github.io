Threat Actor Profiling

Ransomware TTP Analysis & Live Threat Intelligence

Project Overview
Structured profiling of known ransomware groups, focusing on TTP patterns, infrastructure behavior, and operational methodology. Analysts leverage live threat intelligence feeds to stay informed about emerging campaigns and track adversary evolution in real time.
Hands-On Replication Methodology
01 Set up a small AD environment (1 Domain Controller, 2 Workstations, 1 File Server).
02 Simulate initial access attempts using safe brute-force tools or test accounts.
03 Deploy benign credential extraction scripts to understand telemetry — never use actual malware.
04 Track lateral movement by creating mock services and monitoring Event Logs.
05 Test file encryption with temporary directories and shadow copy removal in a controlled environment.
