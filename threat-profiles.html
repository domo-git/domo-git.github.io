Lab Objective

Structured profiling of known ransomware groups, focusing on TTP patterns, infrastructure behavior, and operational methodology. This lab allows you to observe adversary behaviors and gain practical insights into enterprise ransomware threats. Follow the instructions to simulate profiling, track indicators, and document patterns for defensive correlation.

Hands-On Profiling Instructions

  • Set up a virtual lab (VMs) replicating a small Active Directory environment.
  • Deploy network monitoring tools like Sysmon and ELK/Graylog for telemetry capture.
  • Collect logs and events from simulated ransomware behavior in a controlled environment.
  • Analyze logs for TTPs: initial access, execution, credential access, lateral movement, and impact.
  • Document operational patterns and map them to MITRE ATT&CK techniques.

LockBit
Observed TTPs: automated propagation, privilege escalation, lateral spread.
Infrastructure behavior: anonymous payment systems, fast file encryption.
Operational methodology: aggressive RaaS campaigns, minimal exposure.
