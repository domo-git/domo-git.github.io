Adversary Emulation Lab – Enterprise Ransomware Simulation

Lab Objective

This lab environment was designed to replicate human-operated ransomware behavior within a controlled Active Directory infrastructure.

Strategic Value

This adversary emulation lab bridges theoretical threat intelligence with hands-on detection engineering validation.

Reproduction Methodology – Controlled Enterprise Simulation Guide

This lab can be replicated in a local virtualized environment using VirtualBox, VMware Workstation, or Hyper-V. The following build configuration was used to simulate enterprise ransomware tradecraft in a safe, isolated lab.

Step 1 – Infrastructure Deployment

  • Deploy Windows Server 2019 as Domain Controller
  • Install Active Directory Domain Services (AD DS)
  • Create domain users and groups
  • Deploy two Windows 10 Enterprise clients
  • Join clients to the domain

Step 2 – Logging Configuration

  • Enable Advanced Audit Policy Configuration
  • Enable Process Creation auditing (Event ID 4688)
  • Enable Logon auditing (4624 / 4625)
  • Enable Directory Service Access logging

Step 3 – Controlled Simulation Execution

  • Simulate RDP authentication attempts
  • Observe Security Event logs
  • Simulate privilege escalation via group nesting
  • Simulate lateral movement via administrative shares
  • Monitor service creation logs (7045)

Step 4 – Defensive Validation

  • Filter logs in Event Viewer
  • Document detection gaps
  • Map activity to MITRE ATT&CK
  • Capture screenshots as forensic evidence

Environment Architecture

  • 1 Windows Server Domain Controller
  • 2 Windows 10 Enterprise Workstations
  • 1 File Server
  • Centralized logging via Windows Event Forwarding
  • Simulated external attacker machine
