Adversary Emulation Lab – Enterprise Ransomware Simulation

Lab Objective

This lab environment was designed to replicate the behavior of human-operated ransomware actors within a controlled Active Directory infrastructure. The goal was to observe real telemetry artifacts, validate detection logic, and understand enterprise attack propagation mechanics from initial access through impact.

Environment Architecture

The lab was built as a segmented virtualized network simulating a mid-sized enterprise. Components included:

  • 1 Windows Server Domain Controller (Active Directory + DNS)
  • 2 Windows 10 Enterprise Workstations
  • 1 File Server hosting network shares
  • Centralized logging via Windows Event Forwarding
  • Simulated external attacker machine

Network segmentation was implemented to replicate realistic internal trust boundaries and lateral movement constraints.

Phase 1 – Initial Access Simulation

Remote Desktop Protocol (RDP) was intentionally exposed within the lab. Weak password policies were configured to simulate poor credential hygiene.

Controlled brute-force attempts were executed to validate:

  • Account lockout policy behavior
  • Event ID 4625 (failed logon) frequency patterns
  • Event ID 4624 (successful logon – type 10)

Phase 2 – Credential Access

Following authenticated access, credential dumping techniques were replicated to simulate LSASS memory extraction behavior.

Observed telemetry included:

  • Abnormal process creation (Event ID 4688)
  • Suspicious handle access to lsass.exe
  • Privilege escalation token assignments

Phase 3 – Privilege Escalation & Group Abuse

Misconfigured nested group memberships were intentionally created within Active Directory to demonstrate privilege escalation without direct credential theft of privileged accounts.

Enumeration activities were logged to identify detection opportunities around:

  • Domain user enumeration
  • Group membership queries
  • Excessive directory read operations

Phase 4 – Lateral Movement

Lateral movement techniques were simulated using:

  • SMB-based remote service creation
  • Administrative share access (C$, ADMIN$)
  • Remote PowerShell sessions

Key artifacts analyzed:

  • Event ID 7045 – New service installed
  • Remote process execution logs
  • Abnormal authentication patterns across hosts

Phase 5 – Impact & Recovery Testing

Controlled encryption simulations were executed against test directories. Prior to encryption, shadow copies were deleted using:

vssadmin delete shadows /all /quiet

Backup service interruption and file share enumeration were analyzed to understand operational impact and recovery time objectives.

Detection Engineering Outcomes

The lab validated detection logic across multiple layers:

  • Authentication anomaly detection
  • Credential dumping behavior monitoring
  • Service creation alerts
  • Shadow copy deletion detection
  • Lateral authentication correlation

Lessons learned reinforced the importance of:

  • Strict MFA enforcement
  • Account lockout thresholds
  • Least-privilege group structuring
  • Centralized log aggregation and correlation
  • Segmentation to contain blast radius

Strategic Value

This adversary emulation lab bridged theoretical threat intelligence with hands-on defensive validation, providing practical insight into enterprise ransomware containment, detection engineering, and incident response preparation.
