Lab Methodology
01Set up isolated AD environment: 1 Domain Controller, 2 Workstations, 1 File Server. Snapshot baseline before simulation.
02Simulate initial access using safe credential spray techniques against test accounts. Monitor Event ID 4625/4624 patterns.
03Deploy benign credential extraction scripts to understand LSASS telemetry — no actual malware used at any stage.
04Track lateral movement by creating mock services and monitoring Windows Event Logs, Sysmon, and Wazuh alerts.
05Validate detection coverage: map each emulated technique to a Sigma rule or Wazuh alert and tune as needed.
