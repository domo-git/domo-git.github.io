Adversary Emulation Lab

Enterprise ransomware simulation · Active Directory · SOC validation

Lab Objective & Strategic Value
Objective
Replicate human-operated ransomware behavior within a controlled Active Directory infrastructure to generate real detection telemetry.
Strategic Value
Bridges theoretical threat intelligence with hands-on detection engineering validation — producing actionable SIEM rules and analyst competency benchmarks.
Scope
All simulation phases are conducted in an isolated virtualized environment. No actual malware is deployed at any stage.

Reproduction Methodology – Click Phase to Expand
STEP 01 Infrastructure Deployment ›
  • Deploy Windows Server 2019 as Domain Controller in VirtualBox / VMware / Hyper-V
  • Install Active Directory Domain Services (AD DS) and promote to DC
  • Create domain users, groups, and OU structure mirroring enterprise layout
  • Deploy two Windows 10 Enterprise clients and join to the domain
  • Configure a file server with shared directories accessible by domain users
STEP 02 Logging Configuration ›
  • Enable Advanced Audit Policy Configuration via Group Policy
  • Enable Process Creation auditing — Event ID 4688 with command line logging
  • Enable Logon auditing — 4624 (success) / 4625 (failure)
  • Enable Directory Service Access logging and object access auditing
  • Configure Windows Event Forwarding to centralise logs from all hosts
STEP 03 Controlled Simulation Execution ›
  • Simulate RDP brute-force authentication attempts from attacker VM — observe 4625 burst
  • Achieve successful logon (4624 Type 10) — flag source IP anomaly
  • Simulate privilege escalation via group nesting and token impersonation
  • Execute benign LSASS access script — observe process handle events (4656)
  • Simulate lateral movement via ADMIN$ share and remote service creation
  • Monitor Event ID 7045 for new service installation on remote hosts
STEP 04 Defensive Validation ›
  • Filter Event Viewer and forwarded logs to surface all emulated attack telemetry
  • Document detection gaps — which techniques generated no alerts?
  • Map all observed activity to MITRE ATT&CK techniques and sub-techniques
  • Capture screenshots and log exports as forensic evidence artifacts
  • Draft SIEM correlation rules based on observed event sequences
