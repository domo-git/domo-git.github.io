Overview

This analysis examines real-world ransomware campaigns through the lens of MITRE ATT&CK. The goal is to map initial access, lateral movement, privilege escalation, and encryption stages, while highlighting observable telemetry for defensive correlation.

Infection Chain

  • Initial Access: Phishing email with macro-enabled attachments or exposed RDP endpoints.
  • Execution: Malicious binaries executed on endpoint; persistence via registry and scheduled tasks.
  • Credential Access: LSASS memory dumps, stolen cached credentials, weak password exploitation.
  • Lateral Movement: SMB and administrative shares; PowerShell and remote service creation.
  • Impact: Controlled encryption of sensitive files; shadow copy deletion to prevent recovery.

Weak Password Hygiene Examples

  • Passwords under 8 characters or default system passwords.
  • Reused passwords across multiple systems or services.
  • Plaintext storage of credentials in scripts or config files.
  • Lack of enforced complexity or MFA.

Observed Behavior & Detection

  • Abnormal logon failures followed by successful RDP authentication (Event ID 4625 → 4624).
  • Suspicious LSASS memory access from unprivileged accounts.
  • Unexpected service creation (Event ID 7045) on multiple hosts.
  • Shadow copy deletion attempts (vssadmin delete shadows /all /quiet).
  • Network-wide lateral authentication anomalies.

Strategic Value

  • Actionable detection rules for SIEM correlation.
  • Insight into enterprise weaknesses such as weak credential policies.
  • Foundation for purple team exercises bridging offense and defense.
