Overview

This analysis examines real-world ransomware campaigns through the lens of MITRE ATT&CK, mapping each phase while highlighting observable telemetry for defensive correlation.

Infection Chain

Initial Access (click to expand)

Phishing emails with macro-enabled attachments or exposed RDP endpoints.

Telemetry: Event IDs 4625, 4624. Weak password hygiene exploited.

Go to Emulation Lab →
Execution
Malicious binaries executed; persistence via registry keys & scheduled tasks. Tools used: PowerShell scripts, remote services.
Credential Access
LSASS memory dumps, stolen cached credentials. Weak password policies highlighted.
Lateral Movement
SMB shares, administrative access, remote PowerShell.
Impact
File encryption simulations; shadow copy deletion (vssadmin delete shadows /all /quiet).

Weak Password Hygiene

  • Passwords under 8 characters or default system passwords
  • Reused across multiple systems/services
  • Stored in plaintext scripts/config files
  • No enforced complexity or MFA

Observed Behavior & Detection

  • Abnormal logon failures → successful RDP authentication
  • Suspicious LSASS memory access
  • Unexpected service creation (Event ID 7045)
  • Shadow copy deletion
  • Lateral authentication anomalies

Strategic Value

  • Actionable SIEM rules
  • Insight into enterprise weaknesses
  • Purple team exercises bridging offense & defense
