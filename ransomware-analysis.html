Case Study 01 – Simulated Human-Operated Ransomware Intrusion

Attack Lifecycle Overview

This simulated intrusion models a human-operated ransomware campaign targeting a mid-sized Windows Active Directory enterprise environment. The attack chain follows the MITRE ATT&CK lifecycle from Initial Access through Impact, with emphasis on credential abuse, privilege escalation, and operator-driven lateral movement.

Initial Access – Exposed RDP & Credential Reuse

Initial access was achieved through brute-force and credential stuffing attempts against an externally exposed RDP service (TCP/3389). The targeted account reused a password previously exposed in public breach datasets and did not have multi-factor authentication enforced.

Weak password hygiene in this context included:

  • Password reuse across VPN, O365, and domain accounts
  • Passwords lacking length complexity (<10 characters, no entropy)
  • No account lockout threshold configured in Active Directory
  • MFA not enforced for remote access services

Successful authentication generated Windows Event ID 4624 (Logon Type 10), indicating remote interactive logon via RDP.

Credential Access – LSASS Memory Extraction

After establishing a foothold, the operator escalated privileges by dumping credentials from LSASS memory using administrative access. Extracted material included plaintext credentials and NTLM hashes for domain users currently logged into the compromised host.

This activity would typically generate:

  • Suspicious access to lsass.exe process memory
  • Event ID 4688 for abnormal process creation
  • Potential EDR alerts for credential dumping behavior

Privilege Escalation – Token Manipulation & Misconfigured Groups

Privilege escalation was facilitated by misconfigured domain group memberships, where a compromised user was indirectly nested within a group granting local administrator rights across multiple hosts.

Token impersonation techniques were used to elevate privileges without requiring direct password knowledge of privileged accounts.

Lateral Movement – SMB & Remote Service Execution

With elevated privileges, the operator enumerated domain systems using native commands and moved laterally via:

  • SMB-based remote service creation
  • Administrative share access (C$, ADMIN$)
  • PowerShell remoting where enabled

This generated service creation events (Event ID 7045) and suspicious remote process execution patterns.

Command-and-Control & Persistence

Persistence was established via scheduled tasks and registry run keys. Outbound HTTPS connections to attacker-controlled infrastructure blended with legitimate encrypted traffic, reducing detection by perimeter-only monitoring solutions.

Impact – Backup Targeting & Double Extortion

Prior to encryption, shadow copies were deleted using vssadmin delete shadows and backup services were disabled. File shares were enumerated to identify high-value data for exfiltration.

Data staging preceded encryption, aligning with double-extortion tactics observed in modern ransomware operations.

Detection Engineering & Defensive Strategy

  • Enforce MFA on all remote authentication endpoints
  • Implement account lockout thresholds to mitigate brute force attempts
  • Monitor LSASS memory access behavior
  • Alert on Event ID 7045 (new service creation)
  • Detect shadow copy deletion commands
  • Apply least-privilege and audit nested group memberships

Lab Validation

Key components of this intrusion were replicated in a segmented lab environment consisting of a Windows Server domain controller, member workstations, and simulated enterprise services.

The lab allowed observation of authentication logs, process creation telemetry, service installation artifacts, and encryption behaviors under controlled conditions.
