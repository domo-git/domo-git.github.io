Overview
This analysis examines real-world ransomware campaigns through the lens of MITRE ATT&CK, mapping each phase of the attack chain and highlighting observable telemetry for purple team correlation. Each stage documents attacker tradecraft alongside SIEM-ready detection signals for defenders.

Initial AccessPhishing & Exposed RDPT1566 · T1078›
Phishing emails deliver macro-enabled Office attachments or compressed executables. Alternatively, attackers exploit internet-facing RDP endpoints with weak or default credentials, conducting automated brute-force campaigns prior to successful authentication.
Telemetry Signals
Event ID: 4625 — Failed Logon (repeated, same source IP) Event ID: 4624 — Successful Logon | LogonType: 10 (RemoteInteractive) Source IP: External — flag for geo-anomaly Threshold: >20 failures in 2 min → brute-force indicator

ExecutionMalicious Binary & PersistenceT1059 · T1053 · T1547›
Malicious binaries are executed via PowerShell or cmd.exe. Persistence is established through registry run keys, scheduled tasks, or new service installation. Remote services are leveraged for staging payloads across the environment.
Telemetry Signals
Event ID: 4688 — Process Creation (PowerShell with encoded args) Event ID: 7045 — New Service Installed Key: HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run Sched Task: schtasks /create — monitor for unusual names/paths
Credential AccessLSASS Dump & Credential HarvestingT1003.001 · T1552›
Attackers target LSASS memory to extract plaintext credentials and NTLM hashes. Weak password policies and credential reuse across systems accelerate lateral movement. Harvested credentials enable pass-the-hash and pass-the-ticket attacks.
Telemetry Signals
Event ID: 4656 — Handle to LSASS requested (GrantedAccess: 0x1010) Event ID: 4688 — Process Created: mimikatz.exe / procdump.exe WinDefend: LSASS memory read blocked (if protected) Alert: Unexpected access to lsass.exe from non-system process
Lateral MovementSMB Pivoting & Remote ExecutionT1021.002 · T1021.006 · T1570›
Using harvested credentials, attackers move laterally via SMB administrative shares, remote PowerShell sessions (WinRM), or PsExec-style service creation on target hosts. Payload staging often occurs through ADMIN$ or C$ shares.
Telemetry Signals
Event ID: 4624 — Logon Type 3 (Network) to internal hosts Event ID: 5140 — Network Share Object Accessed (ADMIN$, C$) Event ID: 7045 — New service on remote host (lateral exec) Alert: Workstation → Workstation SMB (unusual in most orgs)
ImpactFile Encryption & Shadow Copy DeletionT1486 · T1490›
The encryptor is deployed and executed across all reachable hosts. Before or during encryption, shadow copies and backup catalogs are deleted to prevent recovery. Ransom notes are dropped in every encrypted directory.
Telemetry Signals
Command: vssadmin delete shadows /all /quiet Command: wbadmin delete catalog -quiet Command: bcdedit /set {default} recoveryenabled No Alert: Rapid file rename events (extension change) across multiple dirs Alert: Volume Shadow Copy deletion by non-system process

Weak Password Hygiene – Attack Enablers
[!]Passwords under 8 characters or default system/vendor passwords left unchanged.
[!]Credentials reused across multiple systems and services, enabling lateral movement post-dump.
[!]Passwords stored in plaintext within scripts, config files, or Group Policy Preferences.
[!]No enforced password complexity policy or multi-factor authentication on critical accounts.
