Investigation Methodology
01
Define the target. Establish scope — IP range, domain, threat actor alias, or email. Set clear boundaries to avoid scope creep.
02
Passive recon first. Start with read-only sources — WHOIS, passive DNS, Shodan, Censys. Never touch the target directly.
03
Pivot on indicators. Each IOC is a pivot point. A domain leads to an IP → ASN → registrar pattern → other domains.
04
Cross-reference sources. Validate findings across at least two independent sources. Single-source IOCs are unreliable.
05
Map to ATT&CK. Translate infrastructure and behavioural findings to MITRE ATT&CK techniques to build a structured threat profile.
06
Document and share responsibly. Record all findings with timestamps and source citations. Share IOCs via STIX/TAXII where appropriate.
